# goap-editor
A visual editor that generates and tests GOAP actions.

Written in GoLang with Gio UI for the user interface.

# Source Langage:
This editor is written in the GoLang language;

https://go.dev/

# User Interface
The user interface is created using a thir party library called Gio UI;

https://gioui.org/

# Compilation
To complile and run the code execute the following in the parent directory;

go run .
